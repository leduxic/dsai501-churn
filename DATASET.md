# Dataset Documentation

## Dataset

**Name:** Telco Customer Churn (IBM sample dataset)

**Source URL (accessed):**
- Kaggle (original listing): https://www.kaggle.com/datasets/blastchar/telco-customer-churn
- Direct download used in this project (IBM public GitHub mirror, identical file):
  https://raw.githubusercontent.com/IBM/telco-customer-churn-on-icp4d/master/data/Telco-Customer-Churn.csv

**Access date:** 28 September 2026

**File:** `WA_Fn-UseC_-Telco-Customer-Churn.csv` (stored locally as `data/telco_churn.csv`)

**Shape:** 7,043 rows × 21 columns (20 predictors + binary target `Churn`)

**Licence / terms:** The dataset is published for educational and research use.
The Kaggle listing is distributed under the standard Kaggle dataset terms; the
IBM GitHub mirror is provided as a public sample dataset for learning purposes.
No personal or sensitive real-customer data is involved — customer IDs are
synthetic and all records are anonymised.

**Ethics note:** Because the data is anonymised and synthetic, there are no
privacy concerns in its use. The analysis was performed solely for coursework.
